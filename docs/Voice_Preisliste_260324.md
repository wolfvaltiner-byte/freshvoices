6.1  RECHENBEISPIEL KAMPAGNE TV + ONLINE

Ein Auftraggeber bucht einen Sprecher für eine TV + Online Kampagne.
Für TV werden zwei 30 Sekünder produziert. Für die Social Media Kampagne werden aus den Motiven
beider 30 Sekünder 4 weitere Cutdowns (à 15 Sekunden) und 2 Cutdowns à 6 Sekunden produziert.
Lizenzen: Werbliche Nutzung - national für 1 Jahr ab Erstausstrahlung.
(Die Archivgage wird bei Bedarf zusätzlich berechnet.)

| TV-Kampagne / 1 Jahr      |               | 2 x  30 Sek  |                           |     | 1.100 € |
| ------------------------- | ------------- | ------------ | ------------------------- | --- | ------- |
| Online Kampagne / 1 Jahr  |               | 2 x  30 Sek  |                           |     |         |
|                           |               | 4 x  15 Sek  |                           |     |         |
|                           |               | 2 x  6 Sek   |                           |     |         |
|                           |            8  | Spots        | 2.400 + 3 x 300 = 3.300 € |     |         |
Laut Empfehlung der Kampagnenstaffelung insgesamt
| Sprechergage gesamt  |     |     |     | netto 4.400 € |     |
| -------------------- | --- | --- | --- | ------------- | --- |
